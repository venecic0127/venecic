# SCREEN//SECRET
캐릭터의 비밀 휴대폰을 만들고 링크로 공유하는 모바일 웹사이트.

## 구성
- **캐릭터 제작**: 이름, 별명, 소개, 배경화면, 프로필 이미지 URL, 5가지 색상 테마
- **앱 콘텐츠**: 문자 대화, 연락처, 메모, Safari 형식 가상 검색 기록, 일정, 사진 갤러리, 통화 기록
- **미리보기**: 잠금화면 → 홈화면 → 앱별 내용
- **개인 저장**: 브라우저 localStorage에 여러 캐릭터 초안을 자동 저장
- **링크 공유**: 서버 DB를 쓰지 않고, 캐릭터 데이터를 gzip/URL-safe Base64로 압축하여 URL의 `#p=` 부분에 담음
- **가져오기/백업**: 각 캐릭터를 JSON으로 다운로드하고 다시 가져오기
- **복사해서 만들기**: 공유받은 휴대폰을 내 작업실에 복제

## 배포 (GitHub Pages)
1. 이 저장소의 **Settings → Pages** 메뉴로 이동
2. **Build and deployment → Source**: `Deploy from a branch`
3. **Branch**: `main` / `/(root)` 선택 후 **Save**
4. 배포 완료 후 https://venecic0127.github.io/venecic/ 접속

## 중요한 사항
- GitHub Pages에 서버/데이터베이스가 없으므로, 각 사용자의 작성 중인 작품은 **해당 브라우저의 해당 기기에만** 저장됩니다. 브라우저 데이터 삭제, 기기 변경, 시크릿 모드에서는 사라질 수 있으므로 JSON 파일로 백업하세요.
- 공유 링크에 작품 데이터가 직접 포함되므로, **개인정보, 실제 비밀번호, 전화번호 등 민감한 데이터**를 넣으면 안 됩니다. 링크를 얻은 누구나 볼 수 있습니다.
- **공유 링크를 만든 뒤 수정해도 기존 링크는 자동 갱신되지 않습니다.** 변경 후 링크를 다시 만드세요.
- 기록이 많으면 URL이 길어져 일부 메신저에서 잘릴 수 있습니다. 앱에서 URL 길이를 확인하며, 긴 작품은 JSON 백업을 권장합니다.
- 프로필 및 갤러리 이미지는 외부 HTTPS 이미지 URL을 사용합니다. 업로드/이미지 호스팅 기능은 없습니다. 이미지 사이트가 외부 표시를 막으면 나타나지 않을 수 있습니다.
- 새 링크를 만드는 기능은 최신 모바일 Safari/Chrome에서 사용하도록 설계되었습니다.
- 창작용 콘텐츠로만 활용하세요. 캐릭터의 가상 통화 및 메시지가 표시되며 실제 통화·메시지를 조회하지 않습니다.

## 코드 구조
- `index.html`: 페이지 구조와 메타 정보
- `style.css`: 반응형 UI와 휴대폰 미리보기 스타일
- `app.js`: 편집기, 앱 탐색, 저장, 공유 링크 생성/복원
